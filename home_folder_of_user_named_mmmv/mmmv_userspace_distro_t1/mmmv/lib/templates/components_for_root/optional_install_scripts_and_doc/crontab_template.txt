# The use of crontab as root:
#
#     crontab -e -u operatingsystem_username # edits the list of cron-jobs with $EDITOR
#     crontab -l -u operatingsystem_username # lists the cron-jobs of a given user
#
# On Arch Linux based Linux distributions like CachyOS the command is
# "fcrontab" in stead of "crontab".

#--------------------------------------------------------------------------
# Each task is defined as a single line that consists of fields that
# jointly determine, when the task will be run and what command to
# run for the task. The fields that define a task start time accept
# asterisk caharacter ("*") as a field value that has the meaning of
# "every"/"any"/(LaTeX:"\forall"). Tasks will be started based on the
# cron's system daemon's notion of time and time zones. Output of the
# crontab jobs (including errors) is sent through email to the user the
# crontab file belongs to (unless redirected).  The manual pages of
# crontab(5) and cron(8) offer more information.
#
#  ┌───────────────────────────── Task start time       minute {*, [0..59]}
#  │   ┌───────────────────────── Task start time         hour {*, [0..23]}
#  │   │    ┌──────────────────── Task start time day of month {*, [1..31]}
#  │   │    │     ┌────────────── Task start time        month {*, [1..12]}
#  │   │    │     │     ┌──────── Task start time  day of week {*, [0..7](Sunday=0 or 7)}
#  │   │    │     │     │     ┌── command_to_execute
#  │   │    │     │     │     │
#  m   h   dom   mon   dow   command
#  0   5    *     *     1    tar -zcf /var/backups/home.tgz   /home/
# is an example, where all user home folders are backed up at 5 a.m every week.
